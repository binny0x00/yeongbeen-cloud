## 프로젝트 목표

지원 직무가 요구하는 컴포넌트 기반 개발, 반응형 웹, 콘텐츠 관리, Docker와 CI/CD 경험을 하나의 운영 가능한 서비스로 증명합니다.

## 핵심 설계

- Figma 변수와 코드 토큰을 연결한 디자인 시스템
- 프로젝트와 기술 글을 검증하는 Nuxt Content 컬렉션
- 기능별 브랜치, 이슈, Pull Request 기반 개발 흐름
- GitHub Actions에서 lint·format·typecheck·unit test·build·Docker build를 검증하는 CI
- Railway staging 검증 후 production으로 승격하는 CD 파이프라인
- Cloudflare DNS·CDN·HTTPS를 연결한 커스텀 도메인 운영
